色彩系统 · Color Tokens

双主题各 18 个令牌，源自 internal/tui/style.go 的 darkPalette / lightPalette。冷调深蓝基底 + 青色主强调，紫 / 天蓝区分上下行流量，语义四色贯穿状态、延迟与日志。点击色卡复制 HEX。

DARK 默认主题 · 深海蓝
LIGHT 浅色主题 · 晨雾灰

语义约定

令牌用途规则
acc品牌 / 页签选中 / 面板标题 / 快捷键唯一的高饱和主色，选中态以 bg0 文字反白
ok / warn / err内核状态、延迟分级、日志级别延迟 <150ms ok · <250ms warn · 其余 err · ≤0 faint
up / down上行紫 / 下行天蓝流量图、速率摘要、图例固定方向配色，不随主题互换
sel芯片底色 / 列表选中行所有 chip 的统一底，保证多彩而不刺眼
bg0…bg3终端底 / 面板底 / 浮层 / 高亮块四级明度阶梯，rich 模式下面板与栏铺满 bg1
fg / dim / faint正文 / 次要 / 占位三级文字灰阶，键值对 key 用 dim、空值用 faint「—」
03

组件规范 · Components

所有组件由 style.go 的纯函数绘制，零新增依赖（仅复用 charmbracelet/x/ansi 做宽度计算）。以下示例按 dark · colorful 渲染。

Panel · 面板

边框圆角 ┌─┐│└┘，颜色 bd；标题嵌入顶边，acc 色，前后各一空格
内宽outer − 4，内容左右各 1 空格衬垫，超宽截断不折行
richcolorful 模式整行铺 bg1 连续底色（嵌套 reset 后重新上底）

Chip / Dot / 状态

chip = 前景语义色 + sel 底 + 左右各 1 空格；dot ● 用于列表行首。状态色：Running→ok · Starting/Stopping→warn · Stopped→dim · NotInstalled→faint · Error→err。

Latency Bar · 延迟条

填充 █ 数 = delay/30（至少 1，封顶宽度），其余 ░ faint；颜色按 msHex 阈值分级，一眼读出快慢。

Sparkline / Area Chart · 流量图

单行迷你图用 ▁▂▃▄▅▆▇█ 按最大值归一；多行面积图用 █ 填充，下行 down 色、上行 up 色，窗口取最近 w 个采样。

Form · 输入浮层

宽 max(34, min(64, W−8)) 居中；失败时保留输入并在框内以 err 色回显原因（脱敏后）；Ctrl+V 读取系统剪贴板（wl-paste → pbpaste → xclip → xsel）。

Confirm / Resize Notice · 确认与门禁

确认框宽 max(30, min(60, W−8))，y/n 作答；低于 80×24 时整屏替换为尺寸提示，显示最小值与当前值。
04

布局与响应式 · Layout

整屏固定骨架：顶栏 1 行 + 页签栏 1 行 + 分隔线 1 行 + 正文 (H−6) 行 + 操作栏 2 行 + 状态栏 1 行。所有行按显示宽度截断，正文超高裁剪、不足补空行，任何尺寸下不破坏骨架。

07

配置与色彩降级 · Settings & Fallback

外观持久化于 ~/.config/termihomo/settings.yaml（0600，原子写入）。色彩能力按终端环境自动降级，任何环境下骨架与语义不变。

settings.yaml

# Termihomo 外观与行为
refresh-seconds: 3        # 1–300，快照刷新周期
theme: dark               # dark | light | auto
visual: colorful           # colorful | minimal
keys:                       # 可选重映射
  search: /
  test: t
auto 主题：读取 COLORFGBG 末段，值为 15 / 7 / 231 判定浅色终端，否则 dark。校验：非法 theme/visual、越界刷新周期、未知或冲突快捷键一律报错拒绝加载。

色彩能力探测（colorMode）

环境模式输出
NO_COLOR 存在 或 TERM 为空/dumb0纯文本，无任何 SGR
COLORTERM=truecolor/24bit338;2;r;g;b 真彩，HEX 原样
TERM 含 256238;5;n，最近 256 色（含灰阶带）
xterm / screen / tmux / rxvt 前缀3按真彩处理
其他1最近 ANSI 16 色
降级只影响颜色精度：面板边框、glyph、布局、语义结构在 mode 0 下依然完整可用。
